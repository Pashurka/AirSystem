# AirSystem
**AirSystem** — мобільний застосунок для моніторингу якості повітря, призначений для отримання та візуалізації екологічних і метеорологічних даних. Застосунок допомагає користувачам оцінювати стан повітря поблизу свого місцезнаходження, знаходити найближчі станції моніторингу та отримувати рекомендації щодо безпечної поведінки.

## Мета проєкту
Метою розробки є створення мобільного інструменту для моніторингу якості повітря, який забезпечує доступ до актуальних екологічних показників, їх наочне відображення та інформування користувачів про потенційні ризики для здоров'я.

## Основні можливості
- Визначення поточного місцезнаходження користувача.
- Пошук найближчих станцій моніторингу.
- Отримання метеорологічних даних.
- Відображення станцій та інформації на карті Google Maps.
- Побудова графіків показників якості повітря.
- Перегляд екологічних і метеорологічних даних.
- Надсилання інформаційних повідомлень.
- Надання персоналізованих рекомендацій щодо безпечної поведінки.

## Технології
| Технологія | Призначення |
|---|---|
| C# | Реалізація бізнес-логіки |
| Xamarin.Forms | Кросплатформна розробка мобільного застосунку |
| XAML | Проєктування інтерфейсу користувача |
| LINQ | Запити, об'єднання та групування даних |
| Google Maps SDK | Робота з картами та географічними об'єктами |
| Geolocation API | Визначення місцезнаходження користувача |

## Функціональні модулі
**Геолокація та пошук станцій**
Визначення місцезнаходження користувача та пошук найближчих станцій моніторингу для отримання відповідних показників.
**Моніторинг метеорологічних показників**
Отримання та відображення метеорологічної інформації, що використовується для оцінювання умов навколишнього середовища.
**Картографічний модуль**
Інтеграція з Google Maps для відображення географічного розташування станцій моніторингу та просторового представлення інформації.
**Візуалізація даних**
Побудова графіків для наочного відображення рівнів забруднення повітря та пов'язаних показників.
**Повідомлення та рекомендації**
Інформування користувачів про стан якості повітря та надання рекомендацій щодо заходів безпеки в умовах несприятливої екологічної ситуації.
## Робота з даними
Для отримання необхідної інформації використовуються LINQ-запити, що забезпечують об'єднання таблиць і групування даних.
Це дозволяє формувати вибірки для відображення інформації про станції моніторингу, метеорологічні показники та результати спостережень.
## Інтерфейс користувача
Інтерфейс розроблено з використанням XAML та C#. Передбачено навігацію між основними екранами застосунку:
- головний екран;
- навігаційне меню;
- екран пошуку;
- екран карт;
- екран графіків.

## Тестування
Тестування застосунку проводилося на емуляторах та фізичному пристрої:
- планшет Tablet M-DPI з Android 7;
- смартфон Galaxy Nexus з Android 14;
- смартфон Xiaomi Redmi 13.

Перевірялися функціональність, коректність відображення інтерфейсу та стабільність роботи застосунку.

## Запуск проєкту
Для відкриття та запуску AirSystem необхідні:
- Visual Studio з підтримкою Xamarin.Forms;
- відповідний .NET Framework та Xamarin SDK;
- Android SDK;
- емулятор або фізичний Android-пристрій;
- конфігурація Google Maps SDK та необхідні API-ключі.

Клонуйте репозиторій:
```bash
git clone https://github.com/Pashurka/AirSystem.git
```
Відкрийте solution-файл у Visual Studio, відновіть NuGet-пакети та налаштуйте параметри зовнішніх сервісів відповідно до конфігурації проєкту.
